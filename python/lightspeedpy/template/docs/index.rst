Template plugin
===============

This `template` plugin is an example which you should copy if you want to make your own plugin. You should also edit this documentation if you would like to document the plugin. This page's doc file is located in :code:`LIGHTSPEEDPY_DIRECTORY/python/lightspeedpy/YOUR_PLUGIN/docs`, and is called `index.rst`.

If you'd like to provide a jupyter notebook example too, you can just add it to the same docs folder.

To refresh the below autodocumentation, replace :code:`lightspeedpy.template` with :code:`lightspeedpy.YOUR_PLUGIN` in the doc file.
